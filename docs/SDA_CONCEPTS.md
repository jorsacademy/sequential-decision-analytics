# Sequential Decision Analytics: Core Concepts

Sequential Decision Analytics (SDA) studies decisions that are made repeatedly over time while information, uncertainty, and system state evolve.

A useful generic representation is:

1. **State**: information available before a decision,
2. **Action**: the decision selected by a policy,
3. **Uncertainty**: information revealed after the action,
4. **Transition**: how the system moves to its next state,
5. **Contribution or reward**: the value generated by the decision and outcome,
6. **Learning or belief update**: how new observations change future decisions,
7. **Objective**: usually maximizing cumulative reward or minimizing cumulative cost.

Not every SDA model contains all of these components explicitly. Multi-armed bandits, for example, have a minimal observable state but emphasize learning under uncertainty. Dynamic programming models emphasize state transitions and downstream consequences.

## 1. Epsilon-Greedy Multi-Armed Bandit

The epsilon-greedy example demonstrates the basic decision-observation-learning loop.

At each decision round:

- with probability `epsilon`, select an arm randomly,
- otherwise, select an arm with the largest estimated mean reward,
- observe a stochastic reward,
- update the estimate of the selected arm.

The incremental sample-mean update is

```text
Q_n = Q_(n-1) + (R_n - Q_(n-1)) / n
```

This example is useful for introducing exploration versus exploitation.

## 2. Upper Confidence Bound

Upper Confidence Bound (UCB) adds an explicit uncertainty bonus to the estimated value of each arm.

A typical index has the form

```text
UCB(a) = Q(a) + sqrt(c * log(t) / N(a))
```

where:

- `Q(a)` is the estimated reward of arm `a`,
- `N(a)` is the number of times arm `a` has been selected,
- `t` is the current decision round,
- `c` controls the strength of exploration.

Arms with high estimated reward or high uncertainty receive larger indices.

## 3. Thompson Sampling

Thompson Sampling represents uncertainty with probability distributions.

For Bernoulli rewards, a Beta distribution is a convenient conjugate prior. Each arm starts with a Beta prior, a probability is sampled from each posterior, and the arm with the largest sample is selected.

After observing a binary reward:

```text
alpha <- alpha + reward
beta  <- beta + (1 - reward)
```

This provides a compact Bayesian example of sequential learning and decision-making.

## 4. Policy Comparison and Regret

Cumulative reward measures realized performance. Regret measures the performance loss relative to an oracle that always selects the best action.

For a stationary bandit with best expected reward `mu*`, pseudo-regret after `T` rounds can be written as

```text
Regret(T) = T * mu* - expected cumulative reward
```

The comparison script uses repeated simulations because a single stochastic run can be misleading. Averaging over replications produces a more meaningful algorithmic comparison.

## 5. Finite-Horizon Inventory Control

The inventory example introduces explicit state, action, uncertainty, transition, and downstream value.

- **State**: current inventory,
- **Action**: order quantity,
- **Uncertainty**: random demand,
- **Transition**: ending inventory after demand,
- **Contribution**: sales revenue minus ordering, holding, and stockout costs,
- **Horizon**: a finite number of decision periods.

The model is solved with backward induction:

```text
V_t(s) = max_a E[C_t(s, a, W) + V_(t+1)(S')]
```

This demonstrates an important SDA principle that is not visible in a simple bandit: a current decision can affect both immediate contribution and future decision opportunities.

## 6. Markov Decision Processes and Value Iteration

A Markov Decision Process (MDP) makes the state-transition structure explicit. The Markov property means that the current state contains the information required to evaluate future evolution under an action.

For a discounted infinite-horizon problem, the Bellman optimality equation is

```text
V*(s) = max_a E[R(s,a,S') + gamma * V*(S')]
```

The grid-world example uses deterministic transitions, so the expectation reduces to a single next state:

```text
V*(s) = max_a [R(s,a) + gamma * V*(s')]
```

Value iteration repeatedly applies the Bellman optimality operator until the value function converges. A greedy policy is then extracted from the converged value function.

This example is model-based because the transition and reward model are known and used directly by the algorithm.

## 7. Q-Learning

Q-learning solves a related sequential decision problem without requiring the algorithm to use a transition model.

The learned quantity is the optimal action-value function `Q*(s,a)`. After observing a transition `(s, a, r, s')`, the tabular update is

```text
Q(s,a) <- Q(s,a) + alpha * [r + gamma * max_a' Q(s',a') - Q(s,a)]
```

The expression in brackets is a temporal-difference error. It compares the current estimate with a one-step bootstrap target.

The grid-world implementation uses epsilon-greedy exploration during learning. Over repeated episodes, the Q-table becomes sufficient to define a greedy policy.

This creates a useful contrast with value iteration:

- **Value iteration** knows and uses the transition model.
- **Q-learning** learns action values from sampled interaction.

Both methods seek an optimal policy, but they obtain decision-relevant information in different ways.

## A Useful SDA Taxonomy

The examples in this repository can be viewed along two dimensions.

### Learning versus known-model optimization

Learning-oriented examples:

- epsilon-greedy,
- UCB,
- Thompson Sampling,
- Q-learning.

Known-model optimization examples:

- finite-horizon inventory control,
- MDP value iteration.

### Minimal state versus explicit dynamic state

Minimal-state examples:

- stationary multi-armed bandits.

Explicit dynamic-state examples:

- inventory control,
- grid-world MDP,
- Q-learning grid world.

This distinction helps show that Sequential Decision Analytics is broader than either classical dynamic programming or Reinforcement Learning alone.

## Suggested Teaching Sequence

1. Start with epsilon-greedy to introduce sequential learning.
2. Introduce UCB to show optimism under uncertainty.
3. Introduce Thompson Sampling to show Bayesian exploration.
4. Compare the three methods using average cumulative reward and regret.
5. Move to finite-horizon inventory control to introduce state transitions and dynamic programming.
6. Introduce MDP value iteration to formalize stationary Bellman optimality.
7. Introduce Q-learning to show how similar decision logic can be learned without a known transition model.

This sequence connects Optimization, Operations Research, and Reinforcement Learning without requiring a large application-specific model.
